# Data Mining Laboratory Programs (22IS68L)

This repository contains Python implementations for the Data Mining Laboratory syllabus.

## Course Information
- **Department:** Information Science & Engineering
- **Course Code:** 22IS68L
- **Course Title:** Data Mining Laboratory
- **Credits:** 1.5

## Programs Included
- `lab1.py`  → Q1: Identify categorical and real-valued attributes
- `lab2.py`  → Q2: Crucial attributes for credit assessment and simple rules
- `lab3.py`  → Q3: Train a Decision Tree on complete dataset
- `lab4.py`  → Q4: Evaluate training classification accuracy and discuss why not 100%
- `lab5.py`  → Q5: Apply cross-validation with Decision Tree
- `lab6.py`  → Q6: Train with selected subset of attributes
- `lab7.py`  → Q7: Decision Tree and cross-validation with comparison
- `lab8.py`  → Q8: Notes on simple vs complex trees and bias relation
- `lab9.py`  → Q9: Reduced Error Pruning style experiment (implemented using pruning parameter)
- `lab10.py` → Q10: IF-THEN rules, PART-style notes, and OneR comparison
- `lab11.py` → Q11: K-means clustering
- `lab12.py` → Q12: SVM accuracy and comparison with Decision Tree

## Notes
- Some files were originally named with spacing/typo issues and have been normalized.
- Update dataset path/filename in each script as required for your local system.
